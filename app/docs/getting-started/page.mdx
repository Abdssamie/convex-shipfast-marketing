# Getting Started

This guide is the shortest path to running FluxKit locally and understanding where the main building blocks live.

## Prerequisites

- Node.js 20 or later.
- Bun or npm for local development.
- A Convex project for real-time backend features.
- Better Auth, billing, and email provider credentials before production rollout.

## Local setup

<Steps>
### Install dependencies

Run `bun install` or `npm install` in the repository root to install the marketing site and docs dependencies.

### Start the marketing site

Run `bun run dev` or `npm run dev` and open `http://localhost:3000`.
</Steps>

<Callout type="warning">
  Keep private tooling and release workspaces out of the public docs surface.
  This documentation should describe the product and implementation model, not
  internal packaging or testing directories.
</Callout>

## Environment checklist

Before a production deployment, define these groups of variables:

- Site URLs and canonical domains.
- Convex project URLs and deployment targets.
- Better Auth secrets and email settings.
- Billing provider keys and plan configuration.
- Monitoring, analytics, and rate-limiting credentials.
