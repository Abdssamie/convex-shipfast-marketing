# Billing

FluxKit includes plan management patterns for monetized SaaS products. The product exposes billing settings pages, current-plan surfaces, and billing history UI so teams can move quickly from prototype to paid product.

## What this feature includes

- Pricing and upgrade messaging on the marketing site.
- Billing settings views inside the app.
- Current plan summary and billing history components.
- Provider-specific plan configuration hooks.
- A clear boundary between public pricing and account-level billing controls.

## How to use it

<Steps>
### Define your plans first

Document the exact limits, trial rules, and upgrade behavior before wiring provider configuration.

### Connect your billing provider

Add provider credentials, product identifiers, and webhook handling in the application environment.

### Gate premium features

Use plan checks in both UI and backend actions so entitlements are enforced consistently.

### Test the full lifecycle

Verify checkout, upgrade, downgrade, failed payment, cancellation, and invoice-history behavior before launch.
</Steps>

<Callout type="warning">
  Billing bugs are revenue bugs. Keep entitlement logic centralized and test it
  separately from pricing-page copy.
</Callout>
