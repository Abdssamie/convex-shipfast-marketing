# Branding

FluxKit is structured so you can keep a consistent brand across the marketing site, docs, and application shell without duplicating core settings.

## What to customize

- Site name, URLs, social links, and metadata in the shared site config.
- Marketing copy across the landing page, pricing, FAQ, blog, and changelog.
- Product naming inside the app starter and auth emails.
- Docs navigation labels, footer copy, and repository links.

## Recommended approach

- Update shared brand constants first.
- Replace demo links and social profiles before public release.
- Keep the docs URL local to the same domain for better SEO and trust.
- Review Open Graph images, favicons, and canonical URLs together.
