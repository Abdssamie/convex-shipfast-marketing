## Core product areas

- Authentication flows built with Better Auth.
- Organization and team management for multi-tenant SaaS products.
- Subscription billing and plan management.
- Real-time notifications and dashboard workflows.
- Landing pages, blog, changelog, and reusable marketing sections.

## Recommended implementation path

<Steps>
### Review the setup requirements

Start with the local environment, package manager, backend services, and auth configuration described in the getting started guide.

### Enable the app features you plan to ship

Use the feature pages to configure authentication, organizations, billing, notifications, and the dashboard modules your product needs.

### Production harden before launch

Finalize branding, environment variables, analytics, error monitoring, and deployment settings before shipping.
</Steps>
